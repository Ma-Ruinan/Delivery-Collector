# 无人值守 Excel 目标定位

调用只需指定“Excel填写位置：测试对象1/2/3”，不用用户再提供列字母、表头单元格或扩展指令。一次一个对象，比较对象总数不改变收集规则。表头版本/模型以调用为准，保留量化标识；例如受测对象MobileWork1009、模型DSV4，不能沿用表里旧对象和旧模型。

## 自动步骤

1. 默认从数据集文件夹定位测试结果记录表，结合文件名、题号和题名核实。排除问题源素材工作簿和“收集核查记录”中的备份/清单。调用显式路径优先。
2. 按“任务编号/题号/问题编号”表头定位记录工作表和题号列。按“测试对象N”识别其用时、完成情况/说明列，支持普通同行表头和两层合并表头。不固定D/E、F/G或工作表名称。
3. 调用明确指定槽位即授权更新该槽位的对象元信息和本批已确定执行题结果。脚本的 `excel.object_slot` 用整数1/2/3，自动解析并生成headers、sheet、time_column、note_column；不再等待选择确认，也不让用户写技术JSON。
4. 该槽位存在则定点修改。若仅有两个对象而指定第三个，向右新增一组“用时＋任务完成情况、说明”，复制相邻对象列宽、单元格样式和组内合并结构，**仅复制格式、不复制历史值或公式**。若只有一个槽位而指定第三个，补齐空的第二组、第三组，只填写本次第三组。不得挤占已有单元格或重排其它对象。
5. 原工作簿先完整备份，预检不改原件。执行后核验实际表头、题号行、时长说明、样式、原有数据及其他ZIP部件。未执行/未确定题不清除旧值、不记失败；存在这些旧值时在清单注明它们不属于本批，不能当作新结果计数。

本次实际写入的对象表头、用时和说明统一水平及垂直居中，保留字体、边框、填充、换行、数字格式等。脚本为目标单元格追加居中样式副本，原样式定义和其他对象不变；数值未变化但对齐不符也要处理，重复执行不重复追加样式。直接补写时使用 `update_workbook(..., center=True)`；不能把全文所有列统一重排样式。
6. 正常反复执行同槽位保持幂等；不得每次又加一个对象。只改本对象的表头与已确定题记录，原有其他对象内容不动。多个收集窗口同时写同一文件，发现SHA/expected值变化时重新读取最新表、重新定位当前槽位并在新审计目录重试，不能强行覆盖；重试最多两次，仍冲突则记异常结束，不无限等待。

## 边界

现有脚本适用于标准transitional XLSX、相邻“用时/说明”两列对象组。受保护/加密、题号重复、多个同等候选工作簿/工作表、对象编号冲突、原生Excel Table或复杂非标准布局，不猜测写入、不破坏格式。先用现有工具和证据自主消歧；可用能保留该布局的工具时按相同规则处理。仍不能确定则收集其它明确文件并在最终异常清单说明“Excel未完成”，不临时停等用户。

旧执行计划的显式sheet/列/headers仍兼容，但新调用优先使用object_slot。内部脚本参数是agent在读取表格后形成的，不是输入提示词的负担。
